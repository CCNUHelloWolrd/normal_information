### 前言
**函数装饰器是python的一个高级用法**  

用于简洁的，为现有函数添加新功能，并且不修改原代码，特别的，这是一个输入函数、输出函数的函数。基本原理就是把函数当做变量对待。

**用途**

1. **函数功能不全，为其添加功能**，如比较函数性能时测量运行时间，软件统一处理日志、权限
2. **函数高度模块化，将其变为个性化**，如网页根据账户不同显示不同内容，使用不同算法  
3. **数个简单装饰器，拼凑出复杂功能**，装饰器也是函数，也可以进行函数嵌套

**你将学到**  

标准装饰器，装饰器原理，装饰带参数的函数，用带参数的装饰器装饰，不修改原函数隐藏属性的装饰器

**用装饰器来测量函数运行时长（应用示例）**  

demo2.py 中查看 怎样用装饰器实现我需要的功能  
声明并实现timer装饰器，并检验dp和递归算法解决某个问题的耗时，查看输出果然不出所料

    def timer(func):
        import time
    
        def wrapper(*args, **kwargs):
            start_time = time.perf_counter()    # 开始时间（时间戳）
    
            result = func(*args, **kwargs)      # 执行目标函数
    
            end_time = time.perf_counter()      # 结束时间（时间戳）
            elapsed = end_time - start_time     # 计算时间差
            print(f"[{func.__name__}] 执行耗时: {elapsed:.9f} ")
            return result
        return wrapper
    
    
    @timer
    def recursion_fun(n):
        if n < 1:
            return 0
        if n == 1:
            return 1
        return recursion_fun(n - 1) + recursion_fun(n - 2)
    
    
    @timer
    def dp_fun(n):
        dp = [0, 1]
        for _ in range(2, n + 1):
            dp.append(dp[_ - 1] + dp[_ - 2])
        return dp[n]
    
    
    print(recursion_fun(10))
    print(dp_fun(10))
    
    # 结果：
    #
    # [recursion_fun] 执行耗时: 0.003266600
    # 55
    # [dp_fun] 执行耗时: 0.000003200
    # 55

**装饰器的原理（嵌套？）**

demo2.py 中虽然可以测量函数的运行时间，但是递归的每一次都会测试时间，如何真的运行了文件，就会发现输出真的很多。
显然很烦人，我只想要最外层的函数运行时间，内部我不想要，怎么解决这个问题，或者说问什么会出现这种情况？

假设我们有个装饰器wrapper，有个函数fun_1, 用装饰器wrapper装饰函数fun_1，比较简单的方式是

    @wrapper
    def fun_1(): pass

比较直观的方式是

    fun_1 = wrapper（fun_1()）

在这里wrapper是个函数，他的作用是输入一个函数，处理后返回一个函数，
如果我们使用第一种方式，那么编译器默认我们在定义函数fun_1时，是使用的第二种方式，
因此此后调用函数fun_1时，是已经被装饰的了，所以我们在上面的示例，递归return调用的时被装饰的函数

**原理请看demo3.py**

    def decorator(func):
        def wrapper():
            func()
            print("函数已被装饰")
        return wrapper
    
    
    @decorator
    def fun_1():
        print("我是func1")
    
    
    def fun_2():
        print("我是func2")
    
    
    # 调用一个被装饰的函数
    fun_1()
    fun_2()
    # 利用装饰器装饰函数，然后运行
    fun_2 = decorator(fun_2)
    fun_2()
    
    # 输出：
    #
    # 我是func1
    # 函数已被装饰
    # 我是func2
    # 我是func2
    # 函数已被装饰

**装饰带参数的函数**
在demo1.py中被修饰的函数没有输入和输出，如果我们使用下方装饰器装饰函数，
会发现函数的输入输出没有正常传递

    def decorator(func):
        def wrapper():
            func()
            print("函数已被装饰")
        return wrapper

所以我们需要下面这种写法来解决问题，通过*args, **kwargs来传递输入，
调用函数时传入参数，函数被执行时返回输出结果

    def decorator(func):
        def wrapper(*args, **kwargs):
            result = func(*args, **kwargs)
            print("函数已被装饰")
            return result
        return wrapper

**用装饰器来为项目添加日志**

请看demo4.py

    ##
    # 成功示例
    from functools import wraps
    
    
    def logit(func):
        @wraps(func)
        def with_logging(*args, **kwargs):
            print(func.__name__ + " was called")
            return func(*args, **kwargs)
    
        return with_logging
    
    
    @logit
    def func(x):
        pass
    
    
    print("示例一")
    result = func(4)
    print(func.__name__)
    
    # 输出：
    # 示例一
    # func was called
    # func
    
    ##
    # 失败示例
    
    
    def logit(func):
        def wrapper(*args, **kwargs):
            func(*args, **kwargs)
            print(func.__name__ + " was called")
            return func(*args, **kwargs)
        return wrapper
    
    
    @logit
    def func(x):
        pass
    
    
    print("示例二")
    result = func(4)
    print(func.__name__)
    
    # 输出：
    # 示例二
    # func was called
    # wrapper

很显然示例二也考虑了被修饰函数的输入输出问题，
但是在函数外访问不到原本的函数名了，当然，其他信息也访问不到了，
我们需要使用 **from functools import wraps**来调用python自带的装饰器来解决这个问题

**装饰器嵌套**

细心的话，你会发现上面的示例一，我们在实现装饰器**logit**的时候，
内部也是使用了装饰器，是否可以嵌套装饰器呢，是可以的

请看demo5.py，可以发现，**多个装饰器的装饰前后没有使用顺序和次数限制**,本质上和函数嵌套没有什么区别


    def decorator_1(func):
        def wrapper(*arg, **kwarg):
            print("decorator_1 running")
            result = func(*arg, **kwarg)
            return result
        return wrapper
    
    
    def decorator_2(func):
        def wrapper(*arg, **kwarg):
            print("decorator_2 running")
            result = func(*arg, **kwarg)
            return result
        return wrapper
    
    def decorator_3(func):
        def wrapper(*arg, **kwarg):
            print("decorator_3 running")
            result = func(*arg, **kwarg)
            return result
        return wrapper
    
    
    @decorator_1
    @decorator_2
    @decorator_3
    def fun_1(x):
        return x ** 2
    
    
    @decorator_2
    @decorator_1
    @decorator_1
    def fun_2(x):
        return x ** 2
    
    
    def fun_3(x):
        return x ** 2
    
    
    print(fun_1(2))
    print(fun_2(2))
    print(fun_3(2))
    print(fun_3(fun_3(fun_3(2))))
    print(decorator_1(decorator_1(decorator_1(fun_3)))(2))
    
    # 输出：
    # decorator_1 running
    # decorator_2 running
    # decorator_3 running
    # 4
    # decorator_2 running
    # decorator_1 running
    # decorator_1 running
    # 4
    # 4
    # 256
    # decorator_1 running
    # decorator_1 running
    # decorator_1 running
    # 4

**带参数的装饰器**

函数可以带参数，装饰器当然也可以了，只是这里逻辑比较复杂

查看demo6.py

对于下面的示例，我们定义了装饰器repeat，他是带两个参数的，一个控制功能，一个表示形参。
我们需要定义函数decorator_repeat来装饰函数，decorator_repeat内部为标准的装饰器写法，
同时可以在函数repeat中写其他语句。

那么func是怎么传进去的呢？怎样直接调用？看下面的示例**repeat(3)(greet_2)("Alice")**，
这里repeat(3)传入不可缺省形参num_times为3，repeat(3)(greet_2)进行装饰，
这是因为repeat的返回值才是一个标准的装饰器，这里传入我们需要装饰的函数greet_2，
然后repeat(3)(greet_2)("Alice")调用被装饰的函数，并执行效果。

@repeat(num_times=3)这里repeat(num_times=3)是返回一个装饰器decorator_repeat的，
然后@decorator_repeat执行了对函数进行装饰的操作，后面就是普通的装饰了。

    def repeat(num_times, a = 123):
        def decorator_repeat(func):
            def wrapper(*args, **kwargs):
                for _ in range(num_times):
                    result = func(*args, **kwargs)
                return result
            return wrapper
    
        print(f"a={a}")
        return decorator_repeat
    
    
    @repeat(num_times=3)
    def greet_1(name):
        print(f"Hello, {name}!")
    
    
    def greet_2(name):
        print(f"Hello, {name}!")
    
    
    greet_1("Alice")
    repeat(3)(greet_2)("Alice")
