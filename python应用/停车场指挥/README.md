## 游戏介绍
1. 实现小游戏：挪车  
2. 游玩规则：  
   1. 双击小车，小车会前进直到遇到障碍物或者走出停车场  
   2. 单击道具，再次单击小车，小车的前进方向会发生变化  
   3. 当所有小车移出界面后，游戏胜利  
3. 使用方式：导入本库, 使用函数start()
4. 其他说明：如需修改游戏或素材，请修改对应代码
